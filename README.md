# RobotCrab
🦀 3D-Printed Quadruped Crab Robot

A 3D-printed quadruped ("crab") walking robot powered by micro-servos.

https://github.com/user-attachments/assets/3a31aa29-e53a-4552-b62c-e5a04bc4c16d

## 📖 Overview
This robot features a compact, custom-designed 3D-printed chassis with 4 articulated legs. Each leg utilizes multiple degrees of freedom driven by standard micro-servos to achieve and crab-like lateral movement.

## 🛠️ Hardware 
To build this robot, you will need the following components:

| Component | Quantity | Notes |
| :--- | :---: | :--- |
| **3D-Printed Parts** | 1 Set | Printed in PLA|
| **Micro-Servos** | 8x | MG90S (metal gear) |
| **Microcontroller** | 1x | Arduino Nano, ESP32, or similar |
| **Servo Driver** | 1x | PCA9685 16-Channel PWM Driver (recommended) |
| **Fasteners** | ~30x | M2 / M2.5 screws |
| **Jumper Wires** | 1 Pack | Male-to-Female / male-to-male |
